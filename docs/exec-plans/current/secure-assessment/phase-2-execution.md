Implemented `SectionResource.secure_delivery` with a non-null false default and direct Combined projection (no student override). Runtime `SUPPORTS_SECURE_DELIVERY` uses the existing normalized boolean parser and a runtime lookup. The conditional Yes/No column supports basic/adaptive assessments. Context checks reject unauthorized, unsupported, malformed and invalid-target edits; the changeset also guards enabling.

Bulk apply now lives in `AssessmentSettings.bulk_apply/3`, reloads its source from the server, authorizes the actor, transacts updates with audit records and invalidates the depot after commit. Disabled instances omit the secure key rather than clear policy. Blueprint copying rejects incompatible true policy before partial writes; publication conflict lists preserve existing overrides.

Two nullable token scope FKs, indexes and a pair/context check extend `users_tokens`. Scope is a provider-neutral typed value, installed atomically on a new token with no scope-update API. `Accounts.get_user_session/1` projects the exact token/user/scope using existing expiry. Existing user-only lookup remains unchanged. No caller yet creates scoped credentials through a browser launch.
