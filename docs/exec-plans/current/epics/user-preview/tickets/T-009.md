## Description

## Scope

Add the question-specific Preview action, standalone Question Preview shell, sticky exit banner, and return-to-bank focus behavior using MER-6229’s renderer.

## Acceptance criteria

### Positive

- Every bank question has a secondary keyboard-accessible Preview action named for that question, which opens only its isolated preview.
- The Question Preview banner and exit remain usable while scrolling, at narrow widths, and with increased zoom; entry identifies the preview context.
- Exit preserves bank search, filters, paging/list position, and restores focus to the originating Preview action, with the documented safe fallback when unavailable.
- Verify supported question interactions through MER-6229’s renderer inside the completed shell.

### Negative

- The shell contains no other bank questions, course navigation, instructor preview cards, or answer-key controls.
- Opening or exiting does not edit the question or create a section/learner attempt. No broader bank/filter redesign is included.

## Technical Guidance

Keep the originating React bank mounted while opening the preview in a separate window/tab, following the existing author-preview launch pattern. Preserve the opener target for return focus, with a safe bank destination if the opener is gone. Reuse a small shared banner where suitable; no new bank-state persistence store is needed. MER-6231 owns alignment of the other bank action controls.

Use the parent [F-005](https://eliterate.atlassian.net/browse/MER-6215) for shared feature requirements, design sources, and code evidence. This sub-task is complete when its scoped acceptance criteria above and the applicable shared constraints are satisfied.
