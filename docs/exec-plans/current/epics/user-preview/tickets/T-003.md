## Description

## Technical Guidance

### Delivery requirements

Let instructors and admins switch between Instructor View and Student Preview on the same resource, then return to the place where they originally entered preview.

- **Scope:**
  - Add the accessible perspective selector to the shared header in both perspectives.
  - Preserve the original safe return destination through switching and subsequent course navigation.
  - Support lesson, Learn, container, and adaptive pages, with keyboard operation, announcements, and predictable focus. Hide the global instructor header and perspective selector in activity-bank selection management. Retain its local back control; returning restores the containing page header/selector and focus to the opener or a logical fallback.
- **Technical approach:** Extend the existing instructor header and use the instructor and ordinary delivery route helpers to switch perspectives. Reuse PreviewReturn validation, propagate the original return independently of route-derived presentation, and restore selector focus. Proposed implementation details are provisional; required behavior and binding constraints remain mandatory.
- **Acceptance criteria:**
  - **Positive:**
    - AC1: Authorized entry from the mapped origins shows the active Instructor View or Student Preview label.
    - AC2: Switching on lesson, Learn, container and adaptive pages keeps the same resource and original Return destination through subsequent navigation.
    - AC3: Return reaches the original safe destination or existing fallback.
    - AC4: Name, current choice, expanded state, keyboard activation, Escape, announcements, trigger focus and responsive layout work.
    - AC8: Activity-bank selection management keeps a clearly labeled local back control. Returning restores the containing course page, its header/selector, and focus to the opener or a logical fallback when the opener is unavailable.
  - **Negative:**
    - AC5: Ordinary students receive no selector or privileged return header.
    - AC6: Unsafe/cross-section return destinations cannot escape the existing safe-return boundary.
    - AC7: Intermediate navigation cannot replace the original origin; author preview modes receive no instructor selector.
    - AC9: Activity-bank selection management shows neither the global instructor header nor perspective selector. Existing selection, customization actions, and filters remain unchanged.
- **Size:** L.
- **Feature flags:** None. Expose the selector when its prerequisite routes and presentation are deployed.

### Implementation guidance

- **Scope analysis:** Add the selector to the shared instructor preview header and the authorized Student Preview presentation. Connect the existing safe-return mechanism across both perspectives. Keep local page back navigation separate from the original global Return destination. Own bank management’s header suppression, local back navigation, and return focus within this task. Explanatory notes belong to [F-002](https://eliterate.atlassian.net/browse/MER-6212); guidance is [F-008](https://eliterate.atlassian.net/browse/MER-6218).
- **Sources and design:** [Design Handoff](https://docs.google.com/document/d/1XrwiN86AETdRxxyoGanQE2pAvl484RHPM6w0prWKk6c/edit); [Instructor Interface](https://www.figma.com/design/S8qAFhjjlnRyTHCg2Dyb8p/User-Preview-Overhaul?node-id=484-14126); [student page](https://www.figma.com/design/S8qAFhjjlnRyTHCg2Dyb8p/User-Preview-Overhaul?node-id=484-14996).
- **Analysis:**
  - **Existing behavior:** `Layouts.instructor_preview_header/1` in `lib/oli_web/components/delivery/layouts.ex` renders a static “Instructor view” span and the Return link. `PreviewReturn.resolve/2` in `lib/oli_web/delivery/instructor/preview_return.ex` already sanitizes local destinations and resolves Customize Content, Assessment Settings, and Overview labels. Existing instructor pages pass `return_to`/`request_path`; ordinary lesson session setup does not mount `SetInstructorPreviewReturn`.
  - **Remaining gap:** There is no selector, perspective translation, or equivalent original-return header on ordinary Student Preview. The handoff’s course content/Manage labels need concrete mapping to existing origin routes; replacing the original origin with intermediate Learn/page navigation would lose the required return destination.
  - **Verification:** Inspected header, route helpers, return resolver, and `test/oli_web/live/delivery/instructor/preview_lesson_live_test.exs` safe-return/navigation tests. No tests or browser checks run. Entry-label mapping and focus across full page navigation need child UI analysis; source terminology does not justify inventing additional destinations.
- **Technical analysis:** Extend the existing header into an accessible perspective control using the established component pattern. Use [T-001](https://eliterate.atlassian.net/browse/MER-6222)’s instructor route helpers and ordinary `Student.Utils` delivery helpers to map the current resource, using the route-derived mode from [T-002](https://eliterate.atlassian.net/browse/MER-6223) to construct links for the active perspective. The selector changes the route family rather than setting a separate perspective preference. Initialize and propagate the global return once at entry and keep local `request_path` navigation separate. Reuse `PreviewReturn` sanitization and fallback. Announce the selected view and restore focus to the selector after a change; hide the global header and selector in bank selection management because it has no equivalent student surface. Reuse BankSelectionManagerLive’s local back path and retain its navigation context. Restore the containing page header/selector and focus to the opener or a logical fallback on return; preserve existing bank actions and filters. Verify this flow with keyboard navigation and browser focus checks.
- **Prerequisite handoffs:** [T-001](https://eliterate.atlassian.net/browse/MER-6222)’s instructor routes and [T-002](https://eliterate.atlassian.net/browse/MER-6223)’s route-derived presentation are available. [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226) integrates the unified admin preview identity into this existing selector flow. Exit handoff: the selector has a stable trigger and dismissal/focus behavior for [F-008](https://eliterate.atlassian.net/browse/MER-6218).
- **Sizing analysis:** L; shared header work is bounded, but same-resource routing and original return/focus across LiveView and controller surfaces require coordinated verification.
