## Description

Add the Instructor View / Student Preview selector and original Return destination to the shared preview header. Keep the same resource when switching views and preserve the original entry location through later navigation.

## Technical Guidance

Extend `Layouts.instructor_preview_header/1` using the existing accessible control pattern. Use MER-6222's instructor routes and ordinary `Student.Utils` links to switch perspective; MER-6223 supplies route-based presentation. Reuse `PreviewReturn.resolve/2` and sanitization. Carry the original return destination separately from local page/back navigation; map Course content, Customize content, and Manage to existing routes rather than inventing destinations.

Bank-selection management has no equivalent student view: hide the global header/selector there, retain `BankSelectionManagerLive`'s local back path, and restore the containing page header and opener focus on return. Explanatory notes belong to MER-6212; the discovery callout belongs to MER-6218.

Existing test references: `test/oli_web/live/delivery/instructor/preview_lesson_live_test.exs`.

## Acceptance criteria

- Authorized entry shows the active view. Switching across lesson, Learn, container, and adaptive pages preserves the resource and original Return destination; Return uses that destination or the safe fallback.
- Support descriptive name, selected/expanded state, keyboard navigation, Escape, visible focus, and view-change announcements. Restore selector focus after switching and verify reflow.
- Bank management hides the header/selector, retains local back navigation, and restores opener focus or a logical fallback. Preserve bank selection, customization, and filters.
- Actual learners and separate author previews get no privileged selector/header. Unsafe or cross-section return destinations are rejected; intermediate navigation cannot replace the original origin.
- Extend the existing instructor preview navigation tests and verify full-page navigation/focus in the browser.
