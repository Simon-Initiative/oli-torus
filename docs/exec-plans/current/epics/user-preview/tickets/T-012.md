## Description

## Scope

Apply MER-6232’s accessible information presentation to the existing embedded preview-session failure state.

## Acceptance criteria

### Positive

- Failed preview-session creation shows “Preview is not available for this activity.” using the shared named focus/hover/Escape trigger.
- Runtime verification covers loading, failed responses, and successful embedded interaction in author Page Preview.

### Negative

- Successful embedded previews have no unavailable warning and retain their interactions.
- The change adds no session API, disables no working activity, and leaves ordinary delivery and instructor preview unchanged.

## Technical Guidance

Use OliEmbeddedDelivery.tsx’s existing previewError state and preview_context request. Show the parent Story's exact unavailable message only when a preview session cannot be created. Reuse MER-6232's information-trigger behavior; keep loading and successful embedded sessions intact without changing the session API.
