## Description

Show the parent Story's unavailable message only when embedded preview-session creation fails, using MER-6232's information trigger.

## Technical Guidance

### Size and feasibility

- **Size:** S (1–2 focused engineering days).
- **Single-engineer feasibility:** Good individual assignment. Existing previewError supplies the condition; verify loading, failure, and successful interaction.
- **Estimate basis:** An engineer familiar with Torus; includes implementation and verification, excludes dependency/review waiting time. This is a planning estimate, not a delivery commitment.

`OliEmbeddedDelivery.tsx` already calls `/jcourse/superactivity/preview_context` and records `previewError`. Use that state to display “Preview is not available for this activity.” Keep loading and successful sessions working; no session API change is needed.

## Acceptance criteria

- Failed session creation shows the shared named, keyboard-accessible focus/hover/Escape information trigger.
- Successful embedded previews have no unavailable warning and retain their interactions. Verify loading, failed response, and successful interaction at runtime.
- Preserve supported activities, ordinary delivery, and instructor preview. Do not add an alert or disable a successful session.
