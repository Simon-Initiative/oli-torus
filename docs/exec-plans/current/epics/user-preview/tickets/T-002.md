## Description

## Technical Guidance

### Delivery requirements

Use the URL family to select Instructor View or student presentation, while keeping the actual actor’s permissions and existing persistent progress.

- **Scope:**
  - Instructor routes render instructor presentation and navigation; ordinary delivery routes render student presentation and navigation.
  - Rename the internal delivery presentation assign from `preview_mode` to `instructor_view`, updating its producers and consumers, including delivery layouts, components, and internal navigation-helper options that carry this state.
  - Student Preview includes My Notes, its student default, and learner Class Notes, while hiding instructor-only controls.
  - Make the same student presentation available to project Full Course Preview without requiring the perspective selector. Admin identity provisioning belongs to [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226).
- **Technical approach:** Rename the internal delivery presentation assign from `preview_mode` to `instructor_view` across LiveView/controller setup and delivery layouts, components, and internal navigation helpers. Reuse its existing route-derived value rather than adding a cookie, session preference, or query parameter. Keep presentation separate from actual-role authorization, and preserve distinct author/template/activity preview contracts, including `template_preview_mode` and the client `previewMode` payload; adapt shared boundaries where needed. Apply the flag to verified role-sensitive UI branches while retaining actual-role checks for authorization. Proposed implementation details are provisional; required behavior and binding constraints remain mandatory.
- **Acceptance criteria:**
  - **Positive:**
    - AC1: With the authorized actor/effective user supplied by the entry flow, instructor and admin previews render the applicable perspective and navigate the existing route families. [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226) provides unified admin identity setup.
    - AC2: Student Preview uses student UI, including My Notes/default behavior and learner Class Notes, while keeping the actual actor’s authorization.
    - AC3: Student Preview uses existing persistent attempt/progress handling for its supplied user and introduces no automatic reset. Regular instructors use their own user; [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226) supplies the author-linked admin preview user.
    - AC8: The student-presentation behavior is callable without the [T-003](https://eliterate.atlassian.net/browse/MER-6224) selector, allowing [T-017](https://eliterate.atlassian.net/browse/MER-6238) to opt in its project preview context.
    - AC9: Delivery presentation producers and consumers use `instructor_view`: true for Instructor View and false for ordinary delivery/Student Preview. Relevant layouts, component attributes, internal navigation helpers, and regression tests use the renamed assign consistently.
  - **Negative:**
    - AC5: URL/session manipulation cannot grant another section’s preview access or alter the actor’s role.
    - AC6: Privileged instructor-only controls do not appear in Student Preview; ordinary students and separate author template-preview sessions are unchanged.
    - AC7: Perspective follows the route family without a separate perspective cookie, session preference, or query parameter; this presentation Story introduces no new attempt store or identity mechanism.
    - AC10: The assign rename does not rename unrelated author/template/activity preview flags or payload contracts, change actual-role authorization, or alter existing attempt/progress behavior.

### Implementation guidance

- **Scope analysis:**
  - Apply route-derived presentation to role-dependent UI and navigation links across ordinary and instructor delivery paths.
  - Consume the effective user/actual actor supplied by the entry flow. [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226) owns author-linked admin preview-user creation, enrollment, and adaptive entry; no separate identity store or fallback is introduced here.
  - [T-001](https://eliterate.atlassian.net/browse/MER-6222) owns the route-prefix migration; this Story owns the delivery presentation assign rename and its producers/consumers; [T-003](https://eliterate.atlassian.net/browse/MER-6224) owns the selector and original-return UI; [F-003](https://eliterate.atlassian.net/browse/MER-6213) owns restriction controls. [T-017](https://eliterate.atlassian.net/browse/MER-6238) supplies its project preview context and reuses student presentation.

Admins with a user account already pass admin enrollment checks. [ProductsController](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/lib/oli_web/controllers/products_controller.ex) and [TemplatePreview](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/lib/oli/delivery/template_preview.ex) already create/reuse a hidden instructor and establish its login for template preview.
  - **Remaining gap:** [LessonLive](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/lib/oli_web/live/delivery/student/lesson_live.ex) derives `is_instructor` from the actual role, so [Annotations](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/lib/oli_web/live/delivery/student/lesson/annotations.ex) hides My Notes and selects Class Notes. Admin identity gaps, including adaptive entry without a current user, are handled by [T-004](https://eliterate.atlassian.net/browse/MER-6225), [T-005](https://eliterate.atlassian.net/browse/MER-6226) rather than by this presentation Story.
  - **Verification:** [Template preview tests](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/test/oli/delivery/template_preview_test.exs) and [controller tests](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/test/oli_web/controllers/products_controller_test.exs) cover identity reuse and user preservation; [enrollment tests](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/test/oli_web/live_session_plugs/require_enrollment_test.exs) cover admin access. Development must verify affected UI branches, assign propagation/renaming, route coverage, separation of actual-role authorization from UI presentation, and compatibility with existing author-template sessions. Existing `SetPreviewMode.on_mount/4`, `PreviewPageContext.build/4`, controller assigns, layout/component attributes, and internal helper options are concrete rename targets; separate author/activity runtime preview contracts must be distinguished before editing.
- **Technical analysis:**
  - **Binding constraints:** Preserve actual user/author roles, ordinary Student Preview URLs, existing persistent attempts/progress, and existing author-template behavior. Keep original-return state separate from presentation. [T-017](https://eliterate.atlassian.net/browse/MER-6238) must be able to reuse student presentation without [T-003](https://eliterate.atlassian.net/browse/MER-6224).
  - **Route-derived presentation:** Rename the existing section-delivery presentation flag from `preview_mode` to `instructor_view` and update its LiveView/controller producers, shared layouts/components, navigation-helper options, and callers. Derive its value from route/live-action metadata and equivalent controller setup. This work does not require [T-001](https://eliterate.atlassian.net/browse/MER-6222)’s route-prefix migration: it operates on the existing Instructor View/ordinary delivery route distinction, and [T-001](https://eliterate.atlassian.net/browse/MER-6222) updates route URLs independently. Preserve separate author/template/activity preview flags and the client `previewMode` contract, translating at shared boundaries where needed. Instructor routes select instructor presentation and links; ordinary routes select student presentation and links. Apply this to annotation tabs/defaults and other verified UI branches while keeping actual-role assigns for authorization. Preserve learner Class Notes and supported interactions. No separate perspective cookie, session preference, or query parameter is needed.
  - **Reuse and compatibility:** Reuse `PageContext`, delivery renderers, and existing route helpers. Preserve explicit legacy author-template context when resolving presentation. [T-017](https://eliterate.atlassian.net/browse/MER-6238) supplies its distinct project context and consumes the same student rendering behavior. These implementation choices remain provisional within the binding constraints.
