## Description

Provide Reset Preview to authorized project authors/admins when their managed preview has failed. Replace it with a fresh section built from the latest publication.

## Technical Guidance

Reuse section creation and retirement (`Sections.soft_delete_section/1` where suitable). Recheck project authorization, current association, failed readiness, and live updates server-side using the existing authenticated/CSRF-protected action pattern. A stale/incomplete section with no applicable live job is recoverably failed even when its terminal job record is gone.

Build the replacement completely before atomically switching the project association. Retire the old section but preserve its preview marker. Coordinate reset with Publish, updates, and other resets so obsolete work cannot corrupt the replacement. Reject retired-section preview requests, including admin bypass paths. Establish normal enrollment as needed; MER-6241 owns the preview user integration.

Supply the action and accessible feedback to MER-6236's LiveView. Explain that this resets shared preview progress and other open previews may need reopening. Fresh progress follows from the new section; do not explicitly delete attempts/progress.

## Acceptance criteria

- Authorized regular project authors/admins can recover after failed, cancelled, exhausted, or pruned update jobs. Replacement uses the latest publication and returns through readiness checks.
- Reset is rejected for unauthorized/arbitrary targets, other projects, ordinary sections/products, ready previews, or previews with applicable live updates. Recheck if the failed state changed after display.
- Concurrent reset/Publish/update work preserves one valid current association; obsolete jobs and retired sessions cannot access/replace it. Failed reset keeps the previous failed association recoverable and exposes no partial replacement.
- Current and retired preview sections remain queryable by their markers. Preserve actual accounts, other projects, and normal template sessions; add no deletion, cleanup, or explicit progress-clearing work.
