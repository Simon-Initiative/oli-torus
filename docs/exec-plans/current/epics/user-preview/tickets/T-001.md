## Description

Move the instructor preview route family from `/preview/...` to `/instructor/...`, including generated links and redirects. Keep the same page/resource and original safe return destination.

## Technical Guidance

Update both route scopes in `lib/oli_web/router.ex`, `lib/oli_web/delivery/instructor/preview_routes.ex`, and preview-aware helpers in `lib/oli_web/live/delivery/student/utils.ex`. Include lesson, Learn, container, adaptive, selection-management, and related schedule/assignment navigation. `lib/oli/rendering/content/activity_bank_selection_preview.ex` also contains hard-coded links.

Reuse `AuthorizeSectionPreview` for actual instructor/admin authorization and `PreviewReturn` for safe return validation. Redirect authorized legacy URLs to matching new routes, preserving revision/selection identifiers and safe query context. Keep `PreviewPageContext.build/4` for basic instructor rendering; do not change adaptive persistence. MER-6223 owns the presentation assign rename, and MER-6224 owns the selector.

Design and code references: [Instructor Interface](https://www.figma.com/design/S8qAFhjjlnRyTHCg2Dyb8p/User-Preview-Overhaul?node-id=484-14126); [existing instructor shell PRD](https://github.com/Simon-Initiative/oli-torus/blob/7b97d3a4fd0073fa99f94ce139c6df3659f21154/docs/exec-plans/current/epics/instructor_customizations/instructor_view_shell/prd.md).

Existing test references: `test/oli_web/live/delivery/instructor/preview_lesson_live_test.exs`, `test/oli_web/delivery/section_preview_route_guard_test.exs`.

### Size and feasibility

- **Size:** M.
- **Single-engineer feasibility:** Good individual assignment. Inventory routes and generated links, preserve legacy redirects and return context, and extend authorization tests.

## Acceptance criteria

- New instructor entry points, internal links, and redirects use the new routes and preserve resource/original return context. Authorized legacy links still work.
- Ordinary students and instructors from other sections cannot gain instructor access through either route family. Preserve the existing safe fallback.
- Basic Instructor View creates no learner visits, attempts, scores, or progress events. Adaptive delegation, ordinary delivery, and author preview keep their existing behavior.
- Extend `preview_lesson_live_test.exs` and `section_preview_route_guard_test.exs` for both route scopes, navigation, legacy links, authorization, and product-remix returns. Complete the route inventory during implementation.
