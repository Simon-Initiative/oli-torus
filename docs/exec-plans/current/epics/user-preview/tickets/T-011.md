## Description

Add accessible information triggers for LTI tools, file upload, directed discussion, and configured collaboration placeholders in author Page Preview. Use the parent Story's exact messages.

## Technical Guidance

### Size and feasibility

- **Size:** M (3–5 focused engineering days).
- **Single-engineer feasibility:** Good individual assignment. Establish accessible information-trigger behavior and integrate four content types. Controller-rendered tooltip initialization needs checking.
- **Estimate basis:** An engineer familiar with Torus; includes implementation and verification, excludes dependency/review waiting time. This is a planning estimate, not a delivery commitment.

Reuse suitable tooltip behavior after testing it in the actual server-rendered and React preview contexts. The existing React tooltip is a Bootstrap/title wrapper; the Phoenix tooltip uses a LiveView hook, whose initialization cannot be assumed here. Add only the small shared presentation needed by these renderers.

Update the LTI author-preview warning in `LTIExternalToolDelivery.tsx`. Add mode-scoped messages in `FileUploadDelivery.tsx` and `DirectedDiscussionDelivery.tsx`; show a collaboration placeholder only when page settings enable a space. MER-6233 uses this presentation for embedded failure; MER-6234 uses it for the remaining four types.

## Acceptance criteria

- Each assigned type shows its exact message near the affected content or labeled placeholder. No collaboration placeholder appears without configuration.
- Triggers have descriptive names and tooltip association, open on focus/hover, remain visible while focused/hovered unless dismissed, and close with Escape without moving focus. Tooltips contain no interactive controls.
- Exercise the four types and a supported scored activity in actual author preview. The rest of the page remains reviewable, with working evaluation/hints/reset preserved.
- Add no upload, posting, LTI, or collaboration capability. Do not change ordinary delivery or instructor bank preview, or disable working behavior just to match a warning.
