## Description

## Scope

Provide accessible limitation information triggers in author Page Preview and apply them to LTI tools, file uploads, directed discussions, and configured collaboration placeholders.

## Acceptance criteria

### Positive

- The four assigned content types show the exact messages from the parent Story next to the affected content or labeled placeholder.
- Triggers are named and keyboard reachable, reference their tooltip, open on focus/hover, remain visible while focused/hovered unless dismissed, and close with Escape without moving focus.
- Verify runtime behavior for the four assigned types and a supported scored activity; the rest of the page remains reviewable.

### Negative

- A page without collaboration configuration shows no collaboration placeholder.
- Tooltips contain no interactive controls. Supported evaluation, hints, and reset remain available; ordinary learner delivery and instructor bank preview are unchanged.
- No upload, posting, LTI, or collaboration capability is added.

## Technical Guidance

Reuse suitable existing tooltip behavior after verifying it initializes in the actual controller-rendered and React contexts. Add only the small shared presentation needed by these renderers. Update the LTI author-preview warning; add author-mode upload/discussion messages and the configured collaboration placeholder. MER-6233 owns embedded-session failure integration, and MER-6234 owns the other four limitation types.

Use the parent [F-006](https://eliterate.atlassian.net/browse/MER-6216) for shared feature requirements, design sources, and code evidence. This sub-task is complete when its scoped acceptance criteria above and the applicable shared constraints are satisfied.
