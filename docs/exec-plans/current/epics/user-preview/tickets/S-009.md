# S-009: Explain limited and sample behavior in page preview

- **Status:** Approved and pending creation
- **Qualification:** Qualified. Logic Lab non-persistence, report sample data, survey reset limits, and alternatives behavior already exist. This Story supplies the missing information presentation and preserves those contracts.
- **Lane:** B, third.
- **Ticket:** pending.

## Description

Explain score, sample-data, reset, and strategy-specific limitations for Logic Lab, reports, surveys, and alternatives in author Page Preview.

- **Requirements:** [MER-6158](https://eliterate.atlassian.net/browse/MER-6158), R-006, R-008. Full requirements are in the epic ticket.
- **Scope:**
  - Show the approved no-score, sample-report, and survey no-reset messages while preserving their existing behavior.
  - Keep alternatives’ existing tabs or preference selector and their strategy-specific explanations.
  - Reuse S-008’s accessible information triggers and verify all four types at runtime, completing coverage of the nine preview limitation types.
- **Technical approach:** Add mode-scoped information presentation beside the existing Logic Lab, report, survey, and alternatives renderers. Reuse existing interaction and preview-bridge behavior; add no new scoring persistence, reporting service, survey reset, or alternatives policy. Proposed implementation details are provisional; required behavior and binding constraints remain mandatory.
- **Acceptance criteria:**
  - **Positive:**
    - P1 — Logic Lab opens and displays the exact no-score message; reports label the existing sample dataset with the exact report text; surveys display the exact no-reset explanation.
    - P2 — Alternatives retain the correct tabs/preference selector, strategy-specific explanation, and policy meaning.
    - P3 — All four indicators meet the shared focus/hover/Escape/name/description contract.
    - P4 — Targeted author-page checks exercise all four types and, together with S-008, document coverage of all nine types including supported activity interaction.
  - **Negative:**
    - N1 — Preview records no Logic Lab scores, labels no sample report as real data, and adds no survey Reset action after submission.
    - N2 — The generic all-alternatives message does not replace strategy-specific text.
    - N3 — Supported evaluation, hints, resets outside the limited survey case, and alternative interaction remain available; ordinary delivery and instructor preview are not changed by author-only indicators.
- **Prerequisites:** S-008.
- **Size:** M.
- **Feature flags:** None.
