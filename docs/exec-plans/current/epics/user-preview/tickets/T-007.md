## Description

Connect basic and advanced author Page Preview to the shared components from MER-6227, remove duplicated preview presentation, and apply the Page Preview entry/banner/exit behavior.

## Technical Guidance

### Size and feasibility

- **Size:** L (6–10 focused engineering days).
- **Single-engineer feasibility:** Good individual assignment after shared components exist. Covers basic and advanced integration, removal of duplicated presentation, preserved interactions, and window/focus behavior.
- **Estimate basis:** An engineer familiar with Torus; includes implementation and verification, excludes dependency/review waiting time. This is a planning estimate, not a delivery commitment.

Keep `ResourceController.preview/2`, `AuthoringResolver`, and the preview activity bridge for working content and nonpersistent interaction. Replace the basic preview template's duplicate layout with shared components. Share the applicable advanced delivery wrapper while preserving `app_params`, `previewMode`, `previewSequenceId`, and adaptive runtime behavior; leave other template consumers working.

Keep the existing named-window launch from `editor_live.ex`/`PageEditor.tsx`. Use the secondary Page Preview action and sticky banner. Exit restores the editor and launch-control focus, or a safe authoring fallback if the opener is unavailable.

## Acceptance criteria

- Basic and advanced previews use shared delivery presentation; future presentation changes do not require a separate preview copy.
- Working/unpublished content, selection errors, evaluation/hints/reset, and adaptive sequence selection remain available. Preserve author/project authorization.
- Hide course previous/next, back, outline, DOT, and notes. Banner/exit remain readable and keyboard usable while scrolling and at narrow widths/zoom, without obscuring content or focus.
- Create no learner account, section, enrollment, persisted attempt, or progress merely to render. Verify ordinary delivery and other template consumers remain unchanged.
- Update tests expecting preview page navigation; retain working-content/selection-error/sequence coverage and verify cross-window focus in the browser.
