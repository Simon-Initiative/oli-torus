# S-003: Add the instructor perspective selector and return flow

- **Status:** Approved and pending creation
- **Qualification:** Qualified. The instructor header currently has a static label and a working return link; the two-way selector and propagation into ordinary delivery are missing.
- **Lane:** A, third.
- **Ticket:** pending.

## Description

Let instructors and admins switch between Instructor View and Student Preview on the same resource, then return to the place where they originally entered preview.

- **Requirements:** [MER-6158](https://eliterate.atlassian.net/browse/MER-6158), R-001, R-008. Full requirements are in the epic ticket.
- **Scope:**
  - Add the accessible perspective selector to the shared header in both perspectives.
  - Preserve the original safe return destination through switching and subsequent course navigation.
  - Support lesson, Learn, container, and adaptive pages, with keyboard operation, announcements, and predictable focus. Selection management’s header exception belongs to S-005.
- **Technical approach:** Extend the existing instructor header and use the instructor and ordinary delivery route helpers to switch perspectives. Reuse PreviewReturn validation, propagate the original return independently of route-derived presentation, and restore selector focus. Proposed implementation details are provisional; required behavior and binding constraints remain mandatory.
- **Acceptance criteria:**
  - **Positive:**
    - AC1: Authorized entry from the mapped origins shows the active Instructor View or Student Preview label.
    - AC2: Switching on lesson, Learn, container and adaptive pages keeps the same resource and original Return destination through subsequent navigation.
    - AC3: Return reaches the original safe destination or existing fallback.
    - AC4: Name, current choice, expanded state, keyboard activation, Escape, announcements, trigger focus and responsive layout work.
  - **Negative:**
    - AC5: Ordinary students receive no selector or privileged return header.
    - AC6: Unsafe/cross-section return destinations cannot escape the existing safe-return boundary.
    - AC7: Intermediate navigation cannot replace the original origin; author preview modes receive no instructor selector.
- **Prerequisites:** S-001, S-002.
- **Size:** L.
- **Feature flags:** None. Expose the selector when its prerequisite routes and presentation are deployed.

## Local analysis

- **Requirements analysis:** [R-001](docs/exec-plans/current/epics/user-preview/epic.md#r-001-switch-instructor-perspectives-without-losing-context): exact labels Instructor View / Student Preview, entry from course content/Customize Content/Manage, same-page switching, durable original return, keyboard control, state announcements and focus. [R-008](docs/exec-plans/current/epics/user-preview/epic.md#r-008-keep-preview-controls-accessible-and-authorized): authorized controls, safe returns, reflow.
- **Scope analysis:** Add the selector to the shared instructor preview header and the authorized Student Preview presentation. Connect the existing safe-return mechanism across both perspectives. Keep local page back navigation separate from the original global Return destination. Bank management’s header exception is S-005 and guidance is S-006.
- **Sources and design:** [Design Handoff](https://docs.google.com/document/d/1XrwiN86AETdRxxyoGanQE2pAvl484RHPM6w0prWKk6c/edit); [Instructor Interface](https://www.figma.com/design/S8qAFhjjlnRyTHCg2Dyb8p/User-Preview-Overhaul?node-id=484-14126); [student page](https://www.figma.com/design/S8qAFhjjlnRyTHCg2Dyb8p/User-Preview-Overhaul?node-id=484-14996).
- **Analysis:**
  - **Existing behavior:** `Layouts.instructor_preview_header/1` in `lib/oli_web/components/delivery/layouts.ex` renders a static “Instructor view” span and the Return link. `PreviewReturn.resolve/2` in `lib/oli_web/delivery/instructor/preview_return.ex` already sanitizes local destinations and resolves Customize Content, Assessment Settings, and Overview labels. Existing instructor pages pass `return_to`/`request_path`; ordinary lesson session setup does not mount `SetInstructorPreviewReturn`.
  - **Remaining gap:** There is no selector, perspective translation, or equivalent original-return header on ordinary Student Preview. The handoff’s course content/Manage labels need concrete mapping to existing origin routes; replacing the original origin with intermediate Learn/page navigation would violate R-001.
  - **Verification and uncertainty:** Inspected header, route helpers, return resolver, and `test/oli_web/live/delivery/instructor/preview_lesson_live_test.exs` safe-return/navigation tests. No tests or browser checks run. Entry-label mapping and focus across full page navigation need child UI analysis; source terminology does not justify inventing additional destinations.
- **Technical analysis:** Extend the existing header into an accessible perspective control using the established component pattern. Use S-001’s instructor route helpers and ordinary `Student.Utils` delivery helpers to map the current resource, using the route-derived mode from S-002 to construct links for the active perspective. The selector changes the route family rather than setting a separate perspective preference. Initialize and propagate the global return once at entry and keep local `request_path` navigation separate. Reuse `PreviewReturn` sanitization and fallback. Announce the selected view and restore focus to the selector after a change; handle the absence of an equivalent student surface via the S-005 management exception.
- **Prerequisite handoffs:** S-001’s instructor routes and S-002’s route-derived presentation are available. S-016 integrates the unified admin preview identity into this existing selector flow. Exit handoff: the selector has a stable trigger and dismissal/focus behavior for S-006.
- **Sizing analysis:** L; shared header work is bounded, but same-resource routing and original return/focus across LiveView and controller surfaces require coordinated verification.
