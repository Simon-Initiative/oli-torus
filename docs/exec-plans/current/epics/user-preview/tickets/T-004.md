## Description

Replace the existing section-scoped, shared admin preview user with the current admin's author-linked preview user for admin section previews. Reuse that admin's user across authorized sections with instructor enrollment, supporting both Instructor View and Student Preview. Different admins use different preview users.

## Technical Guidance

Consume MER-6220's user resolver, enrollment-role rule, and durable ownership markers; reuse section enrollment operations. Admin preview users receive instructor enrollment, including users first created before the author became an admin and replacements created by reset. Authorize the actual admin and current author-to-preview-user association before provisioning/enrollment. Both perspectives keep this user and role; MER-6226 wires it into entry and activity requests.

`UserAuth.auto_enroll_admin/2` currently selects a section-scoped shared hidden user through `Sections.ensure_hidden_instructor/1`. Replace that selection for admin section previews with MER-6220's author-linked resolver; do not retain the shared singleton as an alternative or fallback. MER-6226 connects this replacement to admin preview entry and activity requests. Preserve shared-user behavior where still required by non-admin flows, and exclude current and superseded author-owned preview users from those shared lookups. Leave existing shared accounts and their progress intact; account deletion and progress migration are outside scope.

## Acceptance criteria

- An admin entering a section with an existing shared hidden instructor uses their own author-linked preview user instead. Admin section previews neither select nor create a shared singleton, including on provisioning failure.
- Two admins previewing the same section use different author-linked users with independent progress. Each admin reuses their own user across authorized sections and both views, whether or not they also have a real learner account. Repeated/concurrent calls establish instructor enrollment without duplicates.
- After Reset Preview User, later entries resolve/enroll the replacement and obtain fresh progress without migrating or clearing old progress.
- Generated enrollment alone grants no access after logout, revoked admin permission, stale association, or forged author/section context.
- Provisioning failure does not select a real learner, another author's user, or shared fallback. Preserve real accounts, ordinary instructors, and non-admin legacy behavior; add no global admin role, second user store, cleanup, or preview marker to real sections.
