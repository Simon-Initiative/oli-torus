## Description

## Scope

Use the existing author-linked preview-user resolver for authorized admins, ensure section instructor enrollment, and prevent author-owned users from being selected by legacy shared-user fallback.

## Acceptance criteria

### Positive

- Authorized admins with or without a real learner account resolve the same current author-linked preview user; repeated/concurrent requests establish one applicable instructor enrollment.
- After Reset Preview User, resolution and enrollment use the replacement identity without migrating or clearing old progress.
- Legacy shared fallback excludes current and superseded author-owned preview users.

### Negative

- Forged ownership, stale associations, logout, or revoked admin access cannot use generated enrollment as independent authorization.
- Provisioning failure does not choose a real learner, another author’s user, or shared fallback. Real accounts, non-admin legacy users, and real section classifications are unchanged.

## Technical Guidance

Reuse MER-6220's resolver and existing enrollment operations. Check the actual authenticated admin and current author-to-preview-user association before provisioning or enrollment. Update the shared-user lookup to exclude all author-owned preview users, including superseded users. Do not replace ordinary instructor identities or add another identity store. MER-6226 owns wiring this capability into the entry/rendering/activity paths.
